# Aller, demo municipal principal — 15 de octubre de 2026

La personalización conserva el esqueleto municipal y la identidad de Planta 14. No activa producción, no instala CMS ni modifica main o dominio.

## Recorrido

Portada → `/aller` → noticias municipales → Fuentes de Invierno / Aller Estelar / naturaleza → agenda → `/aller/panel` → publicar un aviso de prueba → volver al espacio. El guardado es exclusivo del navegador. Lena y los demás espacios siguen disponibles.
